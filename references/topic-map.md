# 自包含主题地图规则

在用户明确提供源视频并要求处理后读取。无需安装额外主题分析技能。

## 获取可核验文本

接受用户指定的视频 URL、本地视频及其 VTT/SRT 或带时间码转写稿。优先使用对应视频已有字幕；通过当前可用且获授权的工具读取。无字幕时可使用当前具备的转写能力，结果须与原音核验。无转写能力时请用户提供带时间码字幕，不伪造原文或时间码。

仅有纯文本可分析候选主题，但必须标记“时间码待对齐”，不能进入剪辑。检查字幕与当前视频版本的时间偏移。任何登录、浏览器 Cookie、额外安装或付费服务需求遵循宿主授权规则，不能假设用户提供链接就授权读取浏览器凭证。

## 选题与剪辑逻辑

- 默认给出两个明显不同、单独观看完整成立的主题。时长按论点自然决定；用户指定目标时长时优先满足，但不为凑时长加入废话。
- 只保留钩子、必要上下文、核心论点、关键例证与收束。删除寒暄、无用铺垫、填充词、自我修正和重复解释，保留理解观点必需的最短上下文。
- 每个主题通常由 1–4 个片段组成，同时比较连续版本与不连续精华拼接；提高信息密度且保持完整自然时优先后者。
- 可按论证逻辑重排，但不能改变因果、时间关系、对象或立场。不得制造原发言没有的新结论。不能改写英文原话来掩盖断词。
- 不能丢失主语或留下无法唯一指向的代词；不要以缺少上文的 because、but、so、this、that 开场。靠前片承接时显式标注听感风险。
- 翻译忠实且口语自然，不添加原文没有的判断或承诺。

## 时间码与输出

对每个片段核验首尾原文，边界落在完整句、自然停顿或可靠语义边界；字幕块边界不能直接当作精确剪辑点。必要呼吸留白可建议前后 0.1–0.4 秒，并与原始语义时间码分开记录。重排时标记源时间顺序改变、音调/环境声/姿态/口型跳变风险。

先给简洁主题对比，再逐主题展示标题、价值主张、预计时长、拼接理由、各片段源时间段/英文/中文/作用/顺序及风险，等待主题地图确认。保存 `topic-map.json`：

```json
{
  "source": {"reference": "用户提供的链接或文件路径", "language": "en"},
  "themes": [
    {
      "id": "theme-1",
      "title": "主题标题",
      "promise": "一句话价值主张",
      "estimated_duration_seconds": 0,
      "segments": [],
      "risks": []
    }
  ]
}
```

以上为空结构示例，不是可执行地图。实际 `themes` 应包含所有保留主题；每个 `segments` 必须非空，每项包含 `order`、`source_start`、`source_end`、`english`、`chinese`、`role`。时间格式为 `HH:MM:SS.mmm`，终点大于起点；`order` 从 1 连续递增，数组顺序即成片顺序；预计时长等于片段时长之和（舍入误差不超过 0.2 秒）。`role` 使用 hook/context/argument/example/payoff/closing。风险写明具体字幕和上下文问题，无风险则为空数组。
