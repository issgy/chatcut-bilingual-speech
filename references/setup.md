# 配置与接入

## 分享与安装

分享整个 `chatcut-bilingual-speech` 文件夹或其压缩包，保留 `SKILL.md`、`references/` 和 `config.example.json` 的相对位置。使用者可让自己的助手将该文件夹安装到当前宿主支持的个人技能目录。安装技能不会自动安装 ChatCut 或连接任何云盘账号。

使用者需要：
- 可创建/编辑时间轴、导入媒体、处理字幕、预览与导出的 ChatCut 连接。
- 能读取自己的风景空镜（B-roll）素材库：本地文件夹需要本地文件读取能力；云盘文件夹需要当前环境中对应云盘的连接器、插件或已认证 CLI，能列举子文件夹与文件并下载所选视频。
- 能把 ChatCut 导出的成片下载到本地，并写入成片保存目录。
- 可读写的任务工作目录；若启用清理，需要可恢复的系统废纸篓操作能力。

按当前工具清单核实能力和认证状态，不依赖作者电脑上的脚本、浏览器会话、字体、路径或个人技能。遵循实际连接器附带的说明；所需服务不可用时报告具体缺项。技能可移植不代表上述外部服务可以省略。

## 配置来源

优先级：本次明确指令 > 用户指定配置文件 > 当前工作区 `chatcut-bilingual-speech.config.json` > 用户级配置 > 随包默认值。配置文件中的相对路径以配置文件所在目录解析；任务输出放在当前可写工作区的独立任务目录中，不写回技能安装目录。

可复制 [config.example.json](../config.example.json) 为工作区的 `chatcut-bilingual-speech.config.json`，填入使用者自己的地址，也可直接在对话中提供，不强制手工编辑 JSON。

- `broll_library.location`：风景空镜素材库根目录，由用户提供，没有默认值。可以是本地文件夹路径，也可以是云盘文件夹的链接或 ID（如 Google Drive、OneDrive、Dropbox 等，只要当前环境有能访问它的工具）。根目录下的子文件夹名即素材分类。来源类型按内容判断：本地路径即本地文件夹；云盘链接按域名识别；只给出无法判断的 ID 或名称时，问清是哪个服务。null 表示尚未配置，不表示允许全盘搜索，也不使用作者或其他人的素材库。
- `delivery.output_dir`：成片保存目录，支持绝对路径或相对配置文件所在目录的路径。目录不存在时自动创建；不可写时报告阻塞，不改存到其他位置。成片目录必须独立于本次任务的临时目录和素材库，永远不在清理范围内。
- `subtitle_style`：待审核的起始样式，数值按 1080p 像素解释；字体为 null 时从实际可用字体中选择支持相应语言的粗体字体。确认后不得为适应一行缩小字号。
- `cleanup.move_task_temporary_files_to_trash`：默认 true；在源视频确认时说明会在全部成片保存并核验成功后将本次临时媒体移入废纸篓。用户可设为 false 保留文件。永不清理用户原有源文件和素材库。

## 用户级配置

用户级配置跨工作区生效，独立于技能安装目录，重装或 `git pull` 技能都不会覆盖：

- macOS / Linux：`~/.config/chatcut-bilingual-speech/config.json`（设置了 `XDG_CONFIG_HOME` 时为 `$XDG_CONFIG_HOME/chatcut-bilingual-speech/config.json`）
- Windows：`%APPDATA%\chatcut-bilingual-speech\config.json`

格式与 `config.example.json` 相同，只需写入已确定的字段。写入时读取已有内容后合并，只改动目标字段，保留其他字段；本地路径一律展开 `~` 后以绝对路径保存。

## 素材库与成片目录：只问一次

`broll_library.location` 与 `delivery.output_dir` 都按以下规则处理：

1. 第一次运行时，若本次指令、用户指定配置文件、工作区配置和用户级配置都没有该字段，在源视频节点顺带询问一次，两项缺失时合并成一次提问。不为此另设确认节点。
   - 素材库：请用户给出本地文件夹路径或云盘文件夹链接，并说明子文件夹名会被当作素材分类。没有默认值，不代为搜索或推荐素材库。
   - 成片目录：给出建议值，macOS 为 `~/Movies/励志金句`，Windows / Linux 为 `~/Videos/励志金句`。用户回复「默认」或类似表述即采用建议值。
2. 得到答案后先验证：素材库须能访问且至少有一个含视频文件的子文件夹，云盘须解析出真实文件夹 ID；成片目录须能创建并可写。验证通过后写入用户级配置，并告诉用户保存在哪个配置文件、以后如何修改。
3. 之后的任务直接使用已保存的值，不再询问；只在汇报时说明素材来自哪个库、成片存到了哪里。
4. 用户在某次对话里临时指定其他素材库或目录时，仅本次生效，不改写用户级配置；用户明确说「以后都用这个」之类时才更新用户级配置。
5. 已保存的素材库无法访问（被删除、权限变化、连接器失效）或成片目录无法创建、不可写时，报告具体原因并请用户给出新值，按第 2 步重新保存。
6. 当前环境无法写入用户级配置时（例如没有主目录写权限），本次照常使用用户给出的值，并说明下次仍会询问，不把配置改写到技能安装目录。

素材库缺失不妨碍主题地图、演讲片段（A-roll）和字幕，只阻塞风景空镜抽取。不将口令、令牌、Cookie 等秘密写入配置或状态文件；云盘只保存文件夹链接或 ID。

分享时只打包示例配置与技能规则，不打包真实用户配置、任务状态、媒体、账号信息或历史项目数据。
